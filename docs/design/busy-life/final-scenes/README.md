# Individual scene artwork

Twelve 2560×1440 PNG scene exports, with an HTML viewer (`index.html`), `script.md` and overview (`all-scenes.png`). Open the viewer and use the arrows or thumbnails. These are still-image compositions; no video or audio has been generated in this pass.

Photography: Higgsfield Seedream 4.5, using the same groomer and caller references to improve identity continuity. Scene 4 uses FLUX.2 Pro Outpaint to extend Bubs’s original Milo photograph to landscape, preserving the original crazy-haired dog. It remains a lower-resolution source than the other images; a 2560 export does not add original captured detail. Milo remains off-screen during caller close-ups rather than changing appearance.

Glass call, appointment and closing treatments are separate HTML/CSS layers exported with the photograph. Scene 7 intentionally continues scene 5’s photography with a changed appointment interface. The open-eyed fuzzy mascot was generated from a visual description after automatic approval review blocked uploading the non-public existing mascot file. No attempt was made to bypass that rejection.

Source jobs and prompts are recorded in generations.json and finishing-corrections.json. Raw files 04 (Milo regeneration), 11 and 12 were superseded; final exports use raw 14, 21 and 22. All raw files are retained for traceability. Frames checked for consistent casting, obvious anatomy issues, readable lettering and scene continuity; small generative differences remain possible. This is finished still artwork for creative review, not a claim of a finished film.

The live marketing site is unchanged. The fictional Happy Paws scenario represents configured incoming AI booking in pilot; the returning-customer interaction is shortened. No automatic generic follow-up promises were added.
